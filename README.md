# FinFlow MVP

Локальный desktop-first прототип приложения личных финансов.

## Самый простой запуск

Откройте `index.html` двойным кликом в Chrome / Edge / Firefox.

Если браузер ограничивает локальные возможности, запустите локальный сервер:

### Linux / macOS
```bash
cd FinFlow_MVP
python3 -m http.server 8080
```
Откройте `http://localhost:8080`.

### Windows
В папке проекта:
```powershell
py -m http.server 8080
```
Откройте `http://localhost:8080`.

## Что уже работает

- стартовый экран: демо или пустая база;
- счета и их балансы;
- расходы, доходы и переводы;
- редактирование операций кликом по операции;
- удаление и создание сущностей;
- бюджеты по категориям;
- регулярные платежи и кнопка «Оплачено»;
- финансовые цели;
- следующий доход;
- неснижаемый резерв;
- расчёт «Свободно до зарплаты»;
- расчёт дневного лимита;
- прогноз до зарплаты;
- базовая аналитика;
- глобальный поиск Ctrl/Cmd+K;
- новая операция Ctrl/Cmd+N;
- светлая/тёмная тема;
- JSON backup/import;
- CSV export операций;
- локальное хранение в браузере.
- расширенное автоопределение категорий по магазинам, сервисам и ключевым словам;
- приоритет длинных фраз: «Яндекс Еда» / «Яндекс Такси» / «Яндекс Плюс» распознаются отдельно;
- новые категории: связь, дом и быт, красота, спорт, животные, кредиты и комиссии, налоги и штрафы;
- обучение на ваших операциях: если один раз вручную выбрать категорию для неизвестного места, FinFlow запомнит её локально.

## Важно

Это MVP для проверки логики и UX. Данные хранятся в localStorage браузера. Для production-версии следующим этапом стоит перенести приложение на React + TypeScript + IndexedDB (Dexie) и добавить unit-тесты бизнес-логики.
